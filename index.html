🚀 구글 워크스페이스 &
앱스스크립트의 이해

1. 구글 워크스페이스의 강력함

구글 드라이브, 문서, 스프레드시트, 설문지(Forms)는 학교 현장의 업무 효율을 극대화하는 훌륭한 도구입니다. 특히 모든 앱이 유기적으로 연결되어 있어 실시간 협업과 데이터 수합에 최적화되어 있습니다.

2. 업무 자동화의 핵심: 앱스스크립트 (Apps Script)

앱스스크립트는 구글 앱들을 내 마음대로 제어할 수 있게 해주는 '마법 지팡이'입니다. 자바스크립트(JavaScript) 기반으로 작동하며, 단순 반복되는 학교 업무를 스크립트 한 번 실행으로 끝낼 수 있습니다.

💡 컨테이너형 앱스스크립트란?
특정 스프레드시트나 문서에 종속(Bound)되어 있는 스크립트를 말합니다. 스프레드시트 상단 메뉴에서 [확장 프로그램] > [Apps Script]를 누르면 바로 접근할 수 있어 초보자가 다루기 가장 쉽고 직관적입니다.

3. 생성형 AI와 프롬프트 엔지니어링

코딩을 전혀 몰라도 걱정할 필요가 없습니다. 챗GPT나 구글 제미나이(Gemini) 같은 생성형 AI에게 우리가 원하는 작동 방식을 "우리말"로 정확히 설명(프롬프트)하면, AI가 완벽한 앱스스크립트 코드를 짜주는 시대입니다. 이번 연수에서는 "질문을 잘 던지는 법"을 실습합니다.

기초 실습

과제 미제출자 자동 안내 메일 발송

🎯 실습 시나리오 구글 클래스룸이나 설문지로 과제를 걷었는데, 미제출자를 일일이 찾아 메일을 보내야 하는 번거로운 상황입니다. 스프레드시트에서 '미제출' 상태인 학생을 자동 필터링하여 맞춤형 안내 메일을 일괄 발송하는 스크립트를 구현합니다.

🛠️ 실습 순서

  1. 상단의 [실습 자료] 탭으로 이동하여 첫 번째 샘플 시트 사본을 복사합니다.
  2. 복사한 시트 메뉴에서 [확장 프로그램] > [Apps Script]를 클릭합니다.
  3. 다시 [실습 자료] 탭으로 이동하여 "미제출 안내 프롬프트"를 복사합니다.
  4. 생성형 AI(제미나이, 챗GPT 등)에 복사한 프롬프트를 붙여넣고 코드를 생성받습니다.
  5. 생성된 코드를 Apps Script 편집기에 붙여넣고 저장(💾)합니다.
  6. 상단의 ▷ 실행 버튼을 누릅니다.
⚠️ [중요] 권한 허용 (초회 실행 시) 스크립트가 내 이메일을 대신 발송해야 하므로 권한 승인이 필요합니다.
실행 시 팝업이 뜨면 다음 순서로 진행하세요:
권한 검토 ➔ 구글 계정 선택 ➔ [고급] 클릭 ➔ (안전하지 않음)으로 이동 ➔ [허용]
심화 실습

기초조사서 개별 시트 자동 생성

🎯 실습 시나리오 학기 초 구글 설문지로 학생 기초 자료를 수합했습니다. 상담을 위해 학생 1명당 1개의 보기 좋은 시트(양식)로 데이터를 분리해야 합니다. 응답 시트의 데이터를 끌어와, '양식' 시트에 값을 채워 넣고 학생 학번으로 개별 시트를 무한 자동 생성합니다.

🛠️ 매핑(Mapping)의 이해

설문지 응답이 한 줄로 모인 "응답시트"의 각 열(A, B, C...) 데이터를 "양식" 시트의 특정 셀(B3, D4...)에 정확히 꽂아 넣는 것을 매핑이라고 합니다. 이 과정이 복잡하기 때문에 생성형 AI에게 셀 위치를 명확하게 지시하는 것이 핵심입니다.

실습 순서

  1. [실습 자료] 탭에서 폼즈 및 스프레드시트 양식 샘플을 확인 및 복사합니다. (두 시트가 한 파일 안에 있어야 합니다.)
  2. 시트 메뉴에서 [확장 프로그램] > [Apps Script]를 엽니다.
  3. [실습 자료] 탭에 있는 길고 구체적인 "심화 실습 매핑 프롬프트"를 복사하여 AI에게 전달합니다.
  4. AI가 짜준 코드를 스크립트 편집기에 붙여넣고 저장 후 실행합니다.
  5. 학생별 시트가 하단에 자동으로 촤르륵 생성되는 마법을 경험합니다!
